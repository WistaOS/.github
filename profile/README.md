## Hi there! 👋
WistaOS is a unofficial modded Windows installation based on [Windows 10](https://en.wikipedia.com/wiki/Windows_10) (WistaOS 10) and [Markdown](https://en.wikipedia.com/wiki/Windows_11)
that's brings a easier, light, private and fast experience, and still be Windows! WistaOS is designed to be not heavily modded, to not break Windows Defender or Windows Update, 
because they are active. WistaOS 10 (26H2) takes up to 8.77 gb (lighter than Tiny10 23H1!) and 9.14 gb with VMware Tools, also removes Microsoft Edge in order to Thorium.
